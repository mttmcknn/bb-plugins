# Thread Diff Viewer

A BB thread right-panel tab for reviewing file changes. Open **New tab → Actions → Thread changes**.

The filter has six scopes:

| Filter | Source |
| --- | --- |
| Last Turn | File patches recorded in the most recent thread turn |
| Uncommitted | Working tree against HEAD, including untracked files |
| Unstaged | Working tree against the index, including untracked files |
| Staged | Index against HEAD |
| Committed | Merge base of the environment's base branch against HEAD |
| Branch | Merge base against the working tree, including untracked files |

Each file uses BB's highlighted diff renderer, which selects the language from its path. Markdown files offer **Code** and **Preview** in the file header. The preview displays the new side: the index for Staged, HEAD for Committed, and the current file for the other filters. In Last Turn, the recorded patch is historical while the preview reads the current file.

The Git filters describe the thread's environment. If multiple threads share one environment, their Git changes appear together. Last Turn uses this thread's timeline.

The viewer refreshes every 15 seconds while open and has a manual refresh button. It shows up to 40 files, clips each patch at 75 KB, and previews Markdown files up to 75 KB. Git operations are read-only.

## Development

The scaffold was generated by `bb plugin new`. The package pins the latest published SDK (0.4.97) for type checking.

```sh
npm install
./node_modules/.bin/tsc --noEmit
bb plugin build .
bb plugin install . --yes
```

After edits, run `bb plugin build .` and `bb plugin reload thread-diff-viewer`.
